# Универсальный образ для X96Q / H618 (Armbian + Openbox)

Образ без секретов: пароли, Wi-Fi и подписка VPN задаются **одним файлом** `/boot/cyt-config.txt`.

## Что внутри
- Armbian 26.02 (ядро 6.12.64), загрузчик SPL `e4` (память 1792 МиБ, без «дыры» 0xB0000000+), DTB с резервом
  `badram` (0x70000000-0x7fffffff, этого куска в чипе нет). Итого ~1474 МБ рабочей памяти.
- Wi-Fi драйвер SSV6006C, Openbox + tint2 (тема Arc-Dark, иконки Papirus), Firefox ESR, Telegram Desktop,
  pipewire + pavucontrol, PCManFM, lxterminal, htop.
- mihomo (Clash.Meta) + веб-интерфейс metacubexd: http://127.0.0.1:9090/ui/
- Графика через GPU (glamor + Panfrost), программный курсор, мышь без автосаспенда USB (`usbhid.mousepoll=8`).
- Списки пакетов сохранены: `sudo apt install ...` работает сразу, без `apt update`.
- Ядро, DTB, загрузчик и `armbian-bsp-cli` закреплены (`apt-mark hold` + pin): `apt update && apt full-upgrade`
  их не трогает. Конфиги, изменённые вами, `apt` не перезаписывает (`--force-confold`).

## Сборка (на компьютере)
    cd linux-image/image
    sudo bash build-image.sh        # 30-60 минут, нужен интернет; результат: ../build/cleanyourtv-x96q.img.xz

## Запись на карту
    xz -dc ../build/cleanyourtv-x96q.img.xz | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

Загрузчик уже внутри образа. При первой загрузке раздел сам растягивается на всю карту.

## Настройка одним файлом
1. Возьмите шаблон `overlay/boot/cyt-config.txt`, заполните нужное.
2. Положите на карту (карта в компьютере): `sudo bash write-config.sh /dev/sdX мой-файл.txt`.
   Или без компьютера с Linux: FAT-флешка с меткой `CYTCONF` и файлом `cyt-config.txt` в корне, вставить в приставку.
3. Включите приставку. После применения пароли и ссылка подписки **стираются из файла**.
   Чтобы поменять настройки позже, снова впишите значения и перезагрузитесь.

Без файла: пользователь `tv`, пароль `tv`, root заблокирован, SSH выключен, Wi-Fi не настроен.

## VPN
- `VPN_MODE=tun` (по умолчанию): весь трафик системы через VPN, Telegram и остальное работает без настройки.
- `VPN_MODE=proxy`: легче для процессора. Firefox настроен автоматически, в Telegram один раз:
  Настройки → Продвинутые → Тип соединения → SOCKS5, 127.0.0.1, порт 7890.
- `VPN_DIRECT_SUFFIXES=ru,su` отправляет эти домены напрямую, мимо VPN.
- Сменить режим или список можно, не вводя ссылку заново: она берётся из уже сохранённого конфига.

## Окно настроек
Значок «Настройки» на столе (или пункт в меню по правой кнопке): Wi-Fi, VPN, аккаунт, экран, система.
Работает и без сети. Пустые поля не меняются. Запрашивает пароль администратора. Файл настроек остаётся
запасным вариантом: значок «Settings (text file)».

## Не проверено на железе
Образ собран и проверен как набор файлов, на самой приставке первой загрузки ещё не было. Проверить после
записи (в этой версии новое: окно настроек и значки на столе проверены на приставке, сам образ с ними ещё нет): растянулся ли раздел (`df -h /`), Wi-Fi, `free -m` (~1474), `systemctl status mihomo`,
лог применения `/var/log/cyt-firstboot.log`.

## Личное
Образ не содержит ваших данных, но если вы сняли его с работающей карты, а не собрали скриптом, в нём будут
ваш Wi-Fi, подписка и сессия Telegram. Такой образ не публиковать.
